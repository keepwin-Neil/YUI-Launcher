# Contributing

Thank you for helping improve YUI Console Launcher.

1. Open an Issue describing the bug or proposed behavior.
2. Keep changes limited to the launcher; do not commit N.E.K.O source,
   character assets, model memory, credentials, generated builds, or local
   settings.
3. Run `npm ci`, `npm run check`, and the relevant build command.
4. For release-related changes, run `npm run verify:release`.
5. Submit a focused pull request and explain any visible UI changes.

Contributions intentionally submitted to this repository are accepted under
the MIT License.
